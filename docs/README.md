# Top News website

Simple static website for the Top News Android application.

## Pages

- `index.html` - Home
- `contact.html` - Contact information
- `privacy.html` - Privacy Policy

The same contact information is available offline in the Android app under
Settings -> About -> Contact Us. The page displays the support email address,
support details, and an Email support button that opens an installed email app.

## GitHub Pages

1. Create a public GitHub repository.
2. Upload all files from this folder.
3. Open Settings -> Pages.
4. Under "Build and deployment", select "Deploy from a branch".
5. Select the `main` branch and `/ (root)`.
6. Save.
7. GitHub will provide the public website URL.

For Google Play, use:
- Website: the URL of `index.html`
- Contact information URL: the URL ending in `/contact.html`

Before publishing, review the Privacy Policy so it accurately reflects the data and services actually used by the app.
